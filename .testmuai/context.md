# Tiny Shop — context for Kane runs

The app under test is Tiny Shop, a demo store running on
http://localhost:3000. It has three pages: the shop (product list + cart),
the checkout form, and the order confirmation page.

Checkout is a demo flow. Use the test card 4242 4242 4242 4242 with any
future expiry and any 3-digit CVC. No real payment is taken and no order
is shipped.

The cart total is the sum of the item prices. Prices are shown in US
dollars with two decimals.
